Dragapult v57 — 팬텀다이브 준비형 휴리스틱 챔피언

목표 전개
1. 첫 자기 턴: 드리피 라인 2개를 우선 확보하고 첫 불꽃/초 에너지를 주력 라인에 붙인다.
2. 두 번째 자기 턴: 드라꼰을 세우고 정찰 지령을 진화 전에 사용한다. 크리스핀/수동 부착으로 서로 다른 공격 에너지를 모은다.
3. 세 번째 자기 턴: 드래펄트 ex의 팬텀다이브를 실행하면서 백업 드리피/드라꼰 라인을 남긴다.
4. 중반: 6개 카운터는 즉시 다중 KO, 다음 턴 묶음 KO, 상대 진화 엔진 차단 순서로 배분한다.
5. 역전: 직전 KO가 있으면 페잔디피티 ex와 불공정 스탬프를 보존·활용하고, 나이트 스트레처는 끊어진 진화/에너지 축을 복구한다.

전술 원칙
- 드라꼰의 정찰 지령을 같은 몸의 드래펄트 진화보다 먼저 사용한다.
- 첫 팬텀다이브가 준비되기 전에는 불꽃/초 에너지를 페잔디피티 ex·나옹 ex·뮤키도리의 교대비로 낭비하지 않고 주력 드리피 라인에 집중한다.
- 단, 벤치에 이미 팬텀다이브가 준비된 드래펄트 ex가 있으면 즉시 교대해 공격할 수 있도록 액티브 서포트 부착을 허용한다.
- 준비된 팬텀다이브를 제트헤드버트보다 우선한다.
- 뮤키도리는 악 에너지와 이동 가능한 피해가 실제 KO 계산에 기여할 때 가장 높게 평가한다.
- 두돈노스는 손이 짧을 때 3장 드로우와 벤치 회수를 동시에 수행한다.
- 버듀는 준비가 덜 된 단 한 번의 아이템 봉쇄 플랜으로 제한한다.
- 보스의 지령은 팬텀다이브의 프라이즈 전환 대상이 있을 때 사용한다.
- 리스키 유적은 자기 저HP 기본 포켓몬의 손해보다 상대 누적 피해와 뮤키도리 회수가 유리할 때만 낸다.

구현 특성
- 고정된 요청 덱 60장을 정확히 사용한다.
- 상대 에이전트 소스와 내장 상대 정책을 포함하지 않는다.
- 런타임 트리 탐색을 끄고 검증된 결정론적 휴리스틱만 사용한다.
- 미확인 상대에서는 매치업 특화 검색 없이 범용 정책으로 동작한다.
- IRL 148개 드래펄트 관측과 v56 패배 리플레이를 이용해 팬텀다이브 준비 실패를 분류했다.
- 양방향 A/B에서 각 정책 3,600게임을 실행했고, v57은 2,194승(60.94%)으로 v56의 2,140승(59.44%)보다 54승 앞섰다.
- 측정 호출 시간은 평균 1.48ms이며 평가 오류는 0건이었다.

상세 평가 결과와 폐기 실험은 HEURISTIC_TRAINING_REPORT.json에 기록되어 있다.

경쟁 유지 업데이트
- 팬텀다이브 종료, 릴리에 순서, 정찰 지령 순서, 노고고치, 얕은 탐색 후보를 v57과 경쟁시켰다.
- 소표본에서 좋아 보인 후보도 확대 동일상태 또는 독립 확인에서 이득이 뒤집히면 모두 폐기했다.
- 플레이 정책은 v57과 동일하며 버전 라벨과 COMPETITION_TRAINING_REPORT.json만 추가했다.
- 이는 v58 성능 향상 주장이 아니라 무회귀 챔피언 유지 결정이다.
